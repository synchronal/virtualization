# io-usb-host-sys

FFI to Apple's [IOUSBHost] framework, through [swift-bridge]. Use
[`io-usb-host`] instead.

macOS only. Development and testing: see the [main README].

[`io-usb-host`]: https://crates.io/crates/io-usb-host
