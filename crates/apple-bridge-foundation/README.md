# apple-bridge-foundation

Foundation as the [`virtualization`] `-sys` crates share it: [objc2]'s objects
and the glue for passing them through [swift-bridge], plus `NSError`,
`NSMutableData`, and `PropertyListValue` as plain Rust.

Internal; no stability promise. Development and testing: see the
[main README].

MIT licensed.

[objc2]: https://github.com/madsmtm/objc2
[swift-bridge]: https://github.com/chinedufn/swift-bridge
