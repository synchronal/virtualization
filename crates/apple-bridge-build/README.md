# apple-bridge-build

The build script the [`virtualization`] `-sys` crates share: generates
[swift-bridge]'s glue, builds the Swift package, and links it.

macOS only. Internal; no stability promise. Development and testing: see the
[main README].

MIT licensed.

[`virtualization`]: https://crates.io/crates/virtualization
[swift-bridge]: https://github.com/chinedufn/swift-bridge
